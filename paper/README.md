# Manuscript

DMLR submission (Journal of Data-centric Machine Learning Research) built from
the committed analysis artifacts. The same source was submitted to TMLR as
#11830 on 2026-08-31 and desk-rejected on 2026-09-06; that state is tagged
`tmlr-11830-submitted`.

| File | Role |
| --- | --- |
| `main.tex` | Manuscript source. Contains no literal numbers. |
| `numbers.tex` | Generated by `scripts/export_paper_numbers.py`. Every numeric claim resolves through a macro defined here. |
| `refs.bib` | Bibliography. |
| `main.pdf` | Build output. |
| `dmlr2e.sty` | Vendored DMLR stylefile, unmodified, from https://github.com/JmlrOrg/dmlr-style-file. |
| `SUBMISSION.md` | Submission packets and records (TMLR, arXiv, DMLR). |

## Build

```bash
make paper      # regenerates artifacts, numbers, then compiles
```

or directly:

```bash
tectonic -X compile paper/main.tex
```

`dmlr2e.sty` loads natbib, graphicx, amssymb and hyperref itself and sets the
bibliography style to plainnat; loading any of them again in `main.tex` is an
option clash. The build uses the template's `[preprint]` option, which the
template recommends while a paper is under review (no volume header, no editor
line). DMLR is single-blind, so the author block is printed and
`scripts/check_anonymity.py --allow-identified` is the gate: it fails if the PDF
names nobody.

## Why there are no numbers in `main.tex`

`scripts/export_paper_numbers.py` reads the committed JSON artifacts and emits
`numbers.tex`. CI regenerates both and fails on any diff, so a figure quoted in
the text cannot drift from the analysis that produced it. If a number in the
paper looks wrong, fix the analysis and rerun; do not edit `numbers.tex`.

## Before submitting (DMLR)

1. **Template as given.** DMLR says format violations can be desk-rejected.
   The vendored `dmlr2e.sty` is unmodified and the template's required parts are
   present: `\begin{keywords}` after the abstract, `\impact{}` (Broader Impact
   Statement) and `\acks{}` (acknowledgements with funding and
   competing-interest disclosure) before the bibliography.
2. **`make verify` is green.** Tests, regenerated artifacts, `numbers.tex` and
   `main.pdf` are byte-identical to the committed ones, and the PDF names the
   author.
3. **No page limit at DMLR**, but a long paper lengthens review. Current build:
   16 pages including references.
4. **Form fields and the paste-ready title/abstract/keywords** are in
   `SUBMISSION.md`; the abstract there is extracted from the source, not copied
   from the PDF.
5. **Preprints are allowed** (DMLR permits concurrent arXiv posting). The arXiv
   package is `make arxiv`.
