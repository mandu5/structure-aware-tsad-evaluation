# Manuscript

TMLR submission built from the committed analysis artifacts.

| File | Role |
| --- | --- |
| `main.tex` | Manuscript source. Contains no literal numbers. |
| `numbers.tex` | Generated by `scripts/export_paper_numbers.py`. Every numeric claim resolves through a macro defined here. |
| `refs.bib` | Bibliography. |
| `main.pdf` | Build output. |
| `tmlr.sty`, `tmlr.bst`, `fancyhdr.sty` | Vendored TMLR stylefiles (Apache 2.0). |

## Build

```bash
make paper      # regenerates artifacts, numbers, then compiles
```

or directly:

```bash
tectonic -X compile paper/main.tex
```

The build uses the vendored TMLR stylefile. If it is removed the preamble falls
back to `article`; the fallback reproduces the anonymous title block so a preview
still matches what reviewers see.

## Why there are no numbers in `main.tex`

`scripts/export_paper_numbers.py` reads the committed JSON artifacts and emits
`numbers.tex`. CI regenerates both and fails on any diff, so a figure quoted in
the text cannot drift from the analysis that produced it. If a number in the
paper looks wrong, fix the analysis and rerun; do not edit `numbers.tex`.

## Before submitting

1. **The stylefile is already here.** `tmlr.sty`, `tmlr.bst` and `fancyhdr.sty`
   are vendored from the official repository (Apache 2.0). Do not edit them:
   TMLR states that altering the formatting "may result in rejection without
   review".
2. **Anonymity is checked automatically.** `scripts/check_anonymity.py` runs as
   part of `make paper` and in CI. It fails if the built PDF contains the author
   name, affiliation, institutional email, GitHub handle, repository name or
   project-page host, or if the anonymous title block is missing. Verified: the
   current build reads "Anonymous authors / Paper under double-blind review".
   Keep `\usepackage{tmlr}` without `[accepted]` or `[preprint]`. This repository
   is public and carries the author's name, so **do not link it from the
   submission**.
3. **Do not submit while another venue holds the work.** TMLR forbids reuse of
   text, figures, or results from anything "submitted in parallel at another
   archival, peer-reviewed venue". Wait for the pending decision to be returned
   before submitting here.
4. **Check length.** "Regular submission" means at most 12 pages of main content,
   counted before references and appendices. Longer submissions get a 4-week
   rather than 2-week review window.
5. **Fill the OpenReview form fields.** Two are required and are not part of the
   PDF: `competing_interests` and `human_subjects_reporting` (enter `N/A` if not
   applicable). There is no checklist field.
6. **Keep the LLM footnote.** TMLR requires that use of LLM tooling be stated
   explicitly "as a footnote on the first page". It is `\footnotetext[1]` in
   `main.tex`.
7. **Supplementary material is optional** (ZIP or PDF, up to 100 MB) and must
   also be anonymized, which includes git history and file metadata if code is
   included.

## ArXiv version

Switch the preamble to `\usepackage[preprint]{tmlr}`, which de-anonymizes and
drops the TMLR running head. Note that arXiv's endorsement rules changed on
2026-01-21: an institutional email alone no longer grants automatic endorsement
for a first-time submitter, so arrange an endorser in advance.
